# Running with Docker

Carrot-Transform is available as a Docker container image, which makes it easy to run without installing Python dependencies locally.

For basic Docker usage with file-based input/output, see [Running Carrot Transform with Docker](/transform/docker/docker_run).

For reading from a database or writing to MinIO / S3 object storage, use the connection strings described in [Database Connection](/transform/db_connection) and [MinIO and S3 Connection](/transform/minio) as the `--inputs` and `--output` arguments.
